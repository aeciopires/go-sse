# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [2.0.0] - 2026-11-16

### Added
- Structured JSON logs (`log/slog`) with `LOG_LEVEL` (`DEBUG`, `INFO` default, `WARN`, `ERROR`) and `trace_id`/`span_id` correlation.
- OpenTelemetry traces and logs exported via OTLP/HTTP when `OTEL_EXPORTER_OTLP_ENDPOINT` is set; per-event spans linked to the connection span.
- Health endpoints `/livez` and `/readyz`; `/health` now reports version, uptime and active connections.
- `-healthcheck` and `-version` flags; Docker `HEALTHCHECK` uses the binary itself.
- Graceful shutdown (`SHUTDOWN_DELAY`, `SHUTDOWN_TIMEOUT`) that also closes open SSE streams.
- `Last-Event-ID` support (event IDs continue after reconnection) and `retry:` hint.
- New metrics: `sse_http_request_duration_seconds`, `sse_session_duration_seconds`, `sse_build_info`, Go runtime and process collectors; exemplars with trace IDs (OpenMetrics).
- Docker Compose stack with Grafana 13.3.1, Loki 3.7.10, Tempo 3.1.1, Prometheus 3.16.0, OpenTelemetry Collector 0.165.0 and Jaeger 2.23.0, pre-integrated and provisioned.
- Grafana dashboard covering metrics, logs and traces (generated by `dashboard/generate.py`).
- Material Design 3 web UI with dark (default) and light mode selector, security headers (CSP).
- Unit tests (race detector, ~97% coverage, minimum 90% enforced), golangci-lint config, Trivy scan target.

### Changed
- Go 1.27 and latest dependencies; code split into `internal/` packages; templates and static files embedded with `go:embed`.
- `update` event payload: `request_count` renamed to `event_id`, added `client_id`.
- `sse_event_duration_seconds` now has sub-millisecond buckets and no longer receives the `session` observation (moved to `sse_session_duration_seconds`).
- Docker image: Alpine 3.24.4, non-root user, static stripped binary, cached dependency layer.
- Makefile: `check-deps`/`install-deps`, `test` with coverage threshold, `lint`, `scan`, `compose-*` targets; `build` no longer upgrades dependencies.

### Fixed
- Goroutine leak in `/sse` when a write failed (unbuffered channel never read).
- Write errors were ignored, so disconnected clients were not detected.
- `/` matched every path, rendering the page for unknown URLs and creating unbounded metric label cardinality (now 404).
- Template and response write errors were ignored.
- `welcome` events were not counted in `sse_events_sent_total`.
- Possible XSS in the frontend (`innerHTML` with stream data).

## [1.0.0] - 2026-02-12

### Added
- Initial release of go-sse application
- Server-Sent Events (SSE) endpoint at `/sse`
- Proper SSE protocol compliance with required headers:
  - `Content-Type: text/event-stream`
  - `Cache-Control: no-cache`
  - `Connection: keep-alive`
- Real-time event streaming with periodic updates
- Frontend dashboard with event display
- Connection management and tracking
- Prometheus metrics integration:
  - HTTP request counting
  - Active connection monitoring
  - Event counter
  - Event processing duration tracking
- Health check endpoint at `/health`
- Docker support with multi-platform builds
- Docker Compose configuration with Prometheus and Grafana
- Helm chart for Kubernetes deployment
- Comprehensive documentation and examples
