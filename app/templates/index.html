About Server-Sent Events (SSE)

  • Protocol: HTTP-based, unidirectional streaming
  • Connection: Persistent TCP connection (keep-alive)
  • Format: text/event-stream Content-Type
  • Caching: Disabled (Cache-Control: no-cache)
  • Compression: Not supported by spec
  • Buffering: Server-side flushing required
  • Auto-reconnect: Built-in browser support
  • Browser Support: All modern browsers

Technical Details

Required Headers:
Content-Type: text/event-stream
Cache-Control: no-cache
Connection: keep-alive
HTTP/1.1 200 OK

Event Format:
id: unique-event-id
event: event-type
data: event-data
