About Server-Sent Events (SSE)

  • Protocol: HTTP-based, unidirectional streaming (server → browser)
  • Connection: persistent TCP connection (keep-alive)
  • Format: text/event-stream Content-Type
  • Caching: disabled (Cache-Control: no-cache)
  • Buffering: server-side flushing after every event
  • Auto-reconnect: built into the browser, resumes with Last-Event-ID
  • Browser support: all modern browsers (EventSource API)
